# 抖音无水印下载

在抖音网页版下载无水印的视频、图文和视频集。Chrome / Edge Manifest V3 浏览器扩展。

> 本目录是可直接加载的扩展目录，无需构建、打包或安装依赖。

姊妹扩展：[TikTok No-Watermark Downloader](https://github.com/Keixhuiq/TikTok-No-Watermark-Downloader)

## 功能

- **无水印下载**：支持单视频、图文（多图）、视频集和混合作品
- **画质选择**：最高 / 次高 / 最低，最高画质失效时自动降级
- **弹窗下载入口**：点击扩展图标可预览当前作品（类型 / 标题 / 作者），一键下载
- **快捷键**：页内 `Shift + D`；全局 `Alt + Shift + D`（可在 `chrome://extensions/shortcuts` 自定义，刻意与 TikTok 版错开避免冲突）
- **文件名模板**：支持 `{title}`、`{author}`、`{id}`、`{date}` 占位符，常用模板一键应用
- **保存位置**：使用系统保存框，自动记住上次位置

## 安装

1. 下载本仓库（Code → Download ZIP，或 `git clone`）
2. 打开 `chrome://extensions/` 或 `edge://extensions/`，右上角开启「开发者模式」
3. 点击「加载已解压的扩展程序」，选择本文件夹

更新：用新版本覆盖旧目录后，在扩展页点击刷新图标即可。

## 使用

打开任意抖音视频 / 图文页面（包括从喜欢、收藏列表打开的弹窗作品），按 `Shift + D`（或全局 `Alt + Shift + D`）即可下载；也可以点击扩展图标，在弹窗中预览作品后点击「下载当前作品」。画质、文件名模板等设置都在弹窗里。

## 注意事项

- 信息流（首页推荐）滚动时当前作品可能识别不准，建议先点开作品再下载
- 如果某天突然识别不到作品，通常是抖音接口结构更新，等待扩展更新即可
- 仅在抖音网页版（www.douyin.com）测试过

## 隐私

- 不收集任何数据，不联网（除下载时直连抖音 CDN）
- 设置仅保存在你自己的浏览器中
- 不会向任何第三方上传浏览记录、账号信息或下载记录

## 开发

代码无构建步骤，纯原生 JS：修改后在扩展页刷新即可。开启弹窗里的「调试日志」，可在浏览器 Console 查看解析过程。
